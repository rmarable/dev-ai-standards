## Choices the spec didn't settle

1. **Block text sources:** AGENTS.md `core` = all of `core.md`; other AGENTS.md blocks = the add-on/stack file's `## Always loaded (`AGENTS.md` block `<name>`)` section; CLAUDE.md blocks = its `## Claude only (`CLAUDE.md`)` section. A template's own non-empty block text is the fallback. No source: the block is left out (CLAUDE.md `state-file` has none today, silently dropped; W2's template has its markers).
2. **Every project gets state-file, planning, multi-session** (kit README + W2 templates leave them unguarded). `--addon` is accepted only for P001 B2's command line and must name one of those three.
3. **Block hash** = exact text between the markers. apply writes `\n<body>\n` (body stripped of outer newlines).
4. **Conditionals:** line-based, no nesting; unknown condition name fails. Valid names: the block list plus `pr`, `no-pr`.
5. **Placeholders:** `{{name}}` with no spaces and not preceded by `$` (so GitHub `${{ ... }}` is untouched); `rules-check.yml` is copied raw. Values: version, choices, name (`--name`, default dir name), owner (`--owner`, default `operator`, as W4's M1 stub), date (today), tier, id (`M1`), title (= name). `topic` isn't filled: task-brief.md is never rendered by apply (copied verbatim to `docs/standards/templates/`).
6. **What apply writes into the project:** AGENTS.md / CLAUDE.md (new from template, or only Standards line + blocks if present); if absent: CHANGELOG.md, `docs/**` and `planning-docs/**` from templates, CLAUDE-STATE.md, `CLAUDE.local.md` (`@CLAUDE-STATE.md`), `.github/workflows/rules-check.yml`, `.github/docs-only-paths` (high-stakes), `.codex/config.toml` (codex). Line merges: `.gitignore`, `.gitattributes`, `.git/info/attributes` (non-comment lines). `.claude/settings.json`: adds snippet `env`, `attribution` keys only where absent, unions `permissions.ask`; `_comment` never copied.
7. **`.claude/rules/state-file.md`** is written from `addons/state-file.md` "## Path rule" with frontmatter `paths: CLAUDE-STATE.md`, treated as kit-owned (in the manifest, overwritten). Frontmatter form unproven until A4.
8. **Kit files copied to `docs/standards/`:** core, refs (diff-review only high-stakes), checks (all three + README), all three always-on add-ons, all templates, the settings snippet; high-stakes adds its add-on and `bin/gate-status`; codex adds its add-on and Codex snippet; the chosen stack file (including `stacks/other.md`, which P001 "Rejected" lists; W2 flagged it). VERSION is not copied (version lives only on the Standards line).
9. Re-apply removes kit files that the old manifest listed and the new choices don't; unselected blocks are removed. Edited kit files are replaced, with a note.
10. **Manifest source:** `--manifest FILE`, else `--base REF`, else `origin/main`, then `main`. Working copy only when there's no base branch or the base has no manifest (first adoption), and the output says so.
11. **Size budget** default 24 KiB of AGENTS.md alone, `--budget` to change.
12. **Read-before paths:** backticked tokens in the `Read` column that contain `/` or end in an extension; skill names, URLs and globs skipped.
13. **Overrides:** HTML comments ignored (W2's template has one); any other non-blank line must be `- <known block>: <text>`.
14. **trailer_check:** applies to merge commits too; the trailer must be in the last paragraph; `--range` used for PRs (W2's workflow). A deletion push checks nothing.
15. **gate-status:** docs-only list at `.github/docs-only-paths` (project-owned, default `planning-docs/`, `docs/adr/`), globs/extensions refused. Copies, binaries, submodules **and symlinks** are never docs only (stricter than the plan's "unless every path is on the list"; the brief said copies, binaries, submodules). Enforcement paths are never docs only even if listed. Self re-runs the base copy (`docs/standards/bin/gate-status` on the base) when its bytes differ; README says to start it from the base copy anyway, since a hostile branch copy could skip that. Counts for `--passed` come from the caller: the script can't prove the run happened.
16. `scripts/check --full` = same steps (kit has no slow tier).
