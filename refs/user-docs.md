# User docs (U1-U6)

Read before editing `README.md`, anything under `docs/` (except the kit copies in
`docs/standards/`), or any other doc a user reads. These rules bind as if they were in `AGENTS.md`.

- **U1 Audience.** Technical non-specialists: they know git and a terminal, not this project's
  internals.
- **U2 Voice.** Terse, exact, informative. Plain declarative sentences, concrete nouns and verbs,
  numbers where they help. Address the reader as "you".
- **U3 Banned.**
  - Marketing words: seamless, powerful, robust, leverage, streamline, effortless, empower,
    unlock, comprehensive, cutting-edge, simply, just.
  - Emoji, exclamation marks, rhetorical questions.
  - Filler intros and recaps.
  - Internal shorthand: plan, decision, milestone or rule IDs; "the operator".
- **U4 Shape.** What it is and the problem it solves, in 2-3 sentences; then a quick start, the
  everyday tasks, the limits stated plainly, and links to a reference doc that holds the detail.
- **U5 Accuracy.** Every statement is true of the code as it is now. Check each flag and command
  against its `--help` or the code.
- **U6 Terms.** Explain a term the first time it appears.
